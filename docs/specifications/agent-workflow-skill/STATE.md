## Traps
- `golangci-lint`'s `exhaustive` is on: a `switch` over `artifact.Origin` needs all three cases explicit. `print.go`'s `switch a.Kind` needed an explicit `case KindBoundAgent` (S07) — the next new `setup.Kind` needs one too.
- `sha256.Sum256(AgentPlanner())` in an `older…Digests` list duplicates the current digest and makes `OriginOlder` unreachable while every render-pinned test stays green. `olderSkillWorkflowDigests` still ships empty.
- yaml.v3 partially fills fields on a `*yaml.TypeError`; `agentfile` decodes `skills:`/`omitClaudeMd:` through `yaml.Node`, never a Go-typed field, or a malformed value drops the whole file.
- **`filepath.WalkDir` does not walk a symlinked directory even as its own root** — verified empirically in S07: symlinking `.claude/agents` itself finds nothing via `Find`. Only a symlinked `.md` *leaf* file is read through its link (an intermediate symlinked path component, e.g. `.claude` itself, IS transparently resolved by Lstat/WalkDir's root argument, so `Find` still works when `.claude` — not `agents` — is the symlink). A test needing "an agent Find still resolves, whose absolute path nonetheless escapes root" must symlink an ancestor of `agents`, not `agents` or the leaf itself.
- **R10's writability pre-check breaks against a symlinked `.claude`** whenever a NEW plugin/skill file must be created under it: `nearestExistingAncestor`'s walk-up eventually Lstats `.claude` directly as its own final target, and Lstat never resolves a symlink at the exact path it is asked to check — reports "not a directory" unconditionally, regardless of what the symlink points to. A test exercising a symlinked `.claude` for another reason (e.g. planBoundAgent's own containment check) must use `DryRun` or pre-materialize every plugin/skill file first, or it trips this unrelated refusal.
- Since S06, a claude-code `Init` call always resolves planner/implementer via `agentfile.ResolveBinding`, so every setup/cli test binding a bare-name role must inject home (`WithHomeDir` / `withSetupOpts`). `cli.Run` exported tests cannot inject home; every `--edit-agents` cli test uses `init_internal_test.go`'s `run()` seam.
- `agentfile` imports `internal/platform/host` for `PluginDir`. Neither `host` nor `artifact` may ever import `agentfile`, or an import cycle results.
- `apply`/`writableTargets`/`printArtifacts` all now take a `boundAgentArts []boundAgentArtifact` parameter (S07) — every existing call site (incl. `apply_internal_test.go`'s white-box tests) needed updating to pass `nil`.

## Traps
- `golangci-lint`'s `exhaustive` is on: a `switch` over `artifact.Origin` needs all three cases explicit, not just `default`. A test-body `switch` over `setup.Action` trips the same linter; use an if-chain.
- `sha256.Sum256(AgentPlanner())` in an `older…Digests` list duplicates the current digest and makes `OriginOlder` unreachable while every render-pinned test stays green. `olderSkillWorkflowDigests` still ships empty; `host-skill`'s own OriginOlder arm is reachable only through `host_internal_test.go`'s white-box `hostSkillRow` call.
- The Gherkin reads `skills: [brief-workflow]` (flow form); brief's own agent renders are a block list. S07's `--edit-agents` shape table must accept *both* forms on a repo's own agent file — only brief's own renders are fixed to the block form.
- yaml.v3 partially fills fields on a `*yaml.TypeError`. "Any Unmarshal error → not a candidate" (Rule 5) is pinned, so `agentfile.findIn`/`Load` decode `skills:`/`omitClaudeMd:` through `yaml.Node`, never a Go-typed field.
- `filepath.WalkDir` does not descend into symlinked directories, but a symlinked `*.md` *file* is read through its link, so `Definition.Path` can resolve outside the repository. S07's Rule 3 ("never edits a file outside the repository") must check the resolved target, not just `Scope`.
- User-level duplicate agent definitions resolve silently; nothing WARNs. UNRULED — final product-vision decides.
- Doctor's row order is `host-plugin, host-hook, host-skill, host-snippet, host-agents, roles, roles-skill`. STATE.md's **init report** order (`hook, skill, agent…, snippet`) is a different list — don't copy it into doctor. `host-skill` checks only `h.Skills()`'s first entry; never route it through `hostHookCheck`.
- Every setup/cli test binding a bare-name role must inject home (`WithHomeDir` / `withSetupOpts`) — since S06, a claude-code `Init` call always resolves planner/implementer via `agentfile.ResolveBinding`, so an un-injected test would read the developer's own `~/.claude/agents`. `cli.Run` exported tests cannot inject home; use `init_internal_test.go`'s `run()` seam.
- S06's init report and doctor's roles-skill WARN deliberately cover different sets: init lists bare-name bindings only, roles-skill also WARNs on `brief:*`. Don't unify them without a product-vision call.
- `agentfile` imports `internal/platform/host` for `PluginDir`. Neither `host` nor `artifact` may ever import `agentfile`, or an import cycle results.
